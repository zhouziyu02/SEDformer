# SEDformer
This is the official implementation of the paper titled **"SEDformer: Event-Synchronous Spiking Transformers for Irregular Telemetry Time Series Forecasting"**
 
## Quick Start

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Train on Wiki2000 dataset:
```bash
bash scripts/train_wike2000.sh
```

3. Train on WikiArticle dataset:
```bash
bash scripts/train_wiki_article.sh
```
